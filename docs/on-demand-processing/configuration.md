# On-Demand Processing — Configuration Reference

Every environment variable, secret and tunable introduced by on-demand
processing and object storage. Unless noted, variables are set in `.env` and
consumed by `docker-compose.yml`. Non-secret Frappe settings are written into
`common_site_config.json` by `infra/frappe/configure_site.py` under the *site
config key* shown; secrets never are.

## Frappe app (`frappe-web`, `frappe-worker`, `frappe-scheduler`)

### Object storage

| Variable | Site config key | Default | Example | Meaning |
|---|---|---|---|---|
| `WEBODM_S3_BUCKET` | `storage_bucket` | *(empty)* | `webodm-prod-4f2a` | Bucket name. **Empty disables object storage**: host disk is the only store, exactly the previous behaviour. |
| `WEBODM_S3_PREFIX` | `storage_prefix` | *(empty)* | `prod/` | Key prefix inside the bucket; must end with `/` if set. |
| `WEBODM_S3_REGION` | `storage_region` | *(empty)* | `eu-central-1` | Bucket region (AWS). Any accepted value for MinIO. |
| `WEBODM_S3_ENDPOINT_URL` | `storage_endpoint_url` | *(empty = AWS)* | `http://minio:9000` | Custom endpoint for S3-compatible services. Setting it implies path-style addressing. |
| `WEBODM_S3_FORCE_PATH_STYLE` | `storage_force_path_style` | `0` | `1` | Force path-style URLs (MinIO). |
| `WEBODM_S3_PRESIGN_TTL` | `storage_presign_ttl` | `900` | `600` | Maximum lifetime (s) of any presigned URL the app issues. Not used by the shipped serving paths. |
| `WEBODM_CACHE_MAX_BYTES` | `storage_cache_max_bytes` | `53687091200` (50 GiB) | `214748364800` | Serving-cache size budget; LRU eviction above it (hourly). |
| `WEBODM_CACHE_IDLE_SECONDS` | `storage_cache_idle_seconds` | `604800` (7 d) | `259200` | Blobs unused for longer are evicted (hourly). |

Secrets (Docker secrets → `*_FILE` → process env; **never** written to site config):

| Secret file | Env in container | Meaning |
|---|---|---|
| `secrets/s3_app_access_key_id.txt` | `WEBODM_S3_ACCESS_KEY_ID` | App (writer) identity. Empty file = boto3 default chain (instance role). |
| `secrets/s3_app_secret_access_key.txt` | `WEBODM_S3_SECRET_ACCESS_KEY` | " |
| — | `WEBODM_S3_SESSION_TOKEN` | Optional STS session token (`_FILE` supported). |

### On-demand compute

| Variable | Site config key | Default | Example | Meaning |
|---|---|---|---|---|
| `PROVISIONER_URL` | `provisioner_url` | *(empty)* | `http://provisioner:5002` | Provisioner base URL. **Empty disables provisioning**: tasks run on static nodes. |
| `WEBODM_COMPUTE_MAX_INSTANCES` | `compute_max_instances` | `5` | `10` | Global cap on live instances (Requested + Provisioning + Ready). |
| `WEBODM_COMPUTE_MAX_INSTANCES_PER_ORG` | `compute_max_instances_per_org` | `2` | `3` | Same, per organization. |
| `WEBODM_COMPUTE_PROVISION_TIMEOUT_SECONDS` | `compute_provision_timeout_seconds` | `900` | `1200` | Node not ready in time → destroyed, task retries with backoff. |
| `WEBODM_COMPUTE_MAX_LIFETIME_SECONDS` | `compute_max_lifetime_seconds` | `43200` (12 h) | `28800` | Hard budget per instance; past it the sweep destroys it and fails the task. Also passed to the provisioner (which caps it by its own `PROVISIONER_MAX_LIFETIME_SECONDS`). |
| `WEBODM_COMPUTE_ORPHAN_GRACE_SECONDS` | `compute_orphan_grace_seconds` | `600` | `900` | Provider-side instance with our tags but no live record, older than this → destroyed. |
| `WEBODM_COMPUTE_LARGE_TASK_IMAGES` | `compute_large_task_images` | `500` | `300` | Image count above which the `cpu-large` class is requested. |

| Secret file | Env in container | Meaning |
|---|---|---|
| `secrets/provisioner_api_token.txt` | `PROVISIONER_API_TOKEN` | Bearer token the app presents to the provisioner. Generated by `scripts/init-secrets.sh`. Same file is mounted into the provisioner. |
| `secrets/node_token_secret.txt` | `WEBODM_NODE_TOKEN_SECRET` | HMAC key (≥ 32 chars) from which each node's per-run bearer token is **derived** (`HMAC-SHA256(secret, "webodm-node-token:<site>:<instance name>")`). Nothing about node tokens is stored in the database. Required when a provisioner is configured; generated by `scripts/init-secrets.sh`. Rotating it invalidates the tokens of live nodes — rotate only when no instance is Ready. Frappe services only; the provisioner never sees it. |

Instance class rule (`compute.instance_class_for`): `cpu`, or `cpu-large` when
`feature-quality`/`pc-quality` is `ultra` or the image count exceeds
`WEBODM_COMPUTE_LARGE_TASK_IMAGES`; a class the provisioner does not offer
degrades to the provider's default class. Users never choose a provider.

Fixed constants in code (change in `processing/task_runner.py` /
`processing/compute.py` if ever needed): `CAPACITY_WAIT_SECONDS = 60`,
`MAX_DESTROY_ATTEMPTS_BEFORE_ALERT = 5`, dispatch backoff and poll tolerance
unchanged (`MAX_DISPATCH_ATTEMPTS = 8`, `MAX_POLL_FAILURES = 15`).

## Geospatial service (`geospatial`)

Environment only (`services/geospatial/app/utils/objectstore.py`). Compose
derives them from the `WEBODM_S3_*` values.

| Variable | Default | Example | Meaning |
|---|---|---|---|
| `S3_BUCKETS` | *(empty = local only)* | `webodm-prod-4f2a` | Comma-separated allow-list of buckets this service may read/write. Any other `s3://` URI is rejected (400). |
| `S3_ENDPOINT_URL` | *(empty = AWS)* | `http://minio:9000` | Custom endpoint (with scheme). |
| `AWS_REGION` / `AWS_DEFAULT_REGION` | *(unset)* | `eu-central-1` | Region for AWS S3. |
| `S3_FORCE_PATH_STYLE` | `true` if an endpoint is set, else `false` | `true` | Path-style addressing (MinIO). |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN` (+ `_FILE`) | *(default chain)* | — | **Raster converter** identity: read `raw/`, `assets/`, `plugin-runs/`; write `assets/*.tif`. Compose mounts `secrets/s3_geospatial_*`. |
| `COG_SCRATCH_DIR` | `/tmp` (`/scratch` in compose) | `/scratch` | Container-local scratch for S3 → S3 conversion. Never the shared sites volume. Size it for the largest raster. |

GDAL range-read tuning is fixed in `gdal_options()`
(`GDAL_DISABLE_READDIR_ON_OPEN=EMPTY_DIR`, merged ranges, 64 MB VSI cache,
32 KB ingested at open).

## Provisioner service (`provisioner`)

Environment only (`services/provisioner/app/config.py`, `providers/aws.py`,
`providers/fixed.py`). `*_FILE` is accepted for every value.

### Core

| Variable | Default | Example | Meaning |
|---|---|---|---|
| `PROVISIONER_PROVIDER` | `none` | `aws` | `none` (disabled — `/provider` reports `enabled: false`), `aws`, or `fixed` (dev only). |
| `PROVISIONER_API_TOKEN` (`_FILE`) | *(unset = no auth)* | — | When set, every request except `/health` needs `Authorization: Bearer`. |
| `PROVISIONER_DEPLOYMENT` | `default` (compose: `SITE_NAME`) | `webodm.local` | Tag value distinguishing this stack's instances from another stack in the same account. Must match the IAM policy's `DEPLOYMENT`. |
| `PROVISIONER_NODEODM_PORT` | `3000` | `3000` | Port NodeODM listens on (and the node exposes). Must match the security group. |
| `PROVISIONER_NODEODM_IMAGE` | `opendronemap/nodeodm:latest` | `opendronemap/nodeodm:latest@sha256:…` | Image the node runs. Pin a digest in production. |
| `PROVISIONER_NODEODM_ARGS` | *(empty)* | `--max_concurrency 8` | Extra NodeODM CLI flags (comma-separated tokens are joined with spaces). |
| `PROVISIONER_MAX_LIFETIME_SECONDS` | `43200` | `28800` | Ceiling for any instance's lifetime; a larger app request is clamped. Drives the in-box self-destruct (`shutdown -h` at lifetime + 10 min). |
| `PROVISIONER_PROBE_TIMEOUT_SECONDS` | `5` | `3` | Timeout of the NodeODM readiness probe. |

### AWS provider (`PROVISIONER_PROVIDER=aws`) — all explicit, no usable defaults

| Variable | Required | Example | Meaning |
|---|---|---|---|
| `PROVISIONER_AWS_REGION` | yes | `eu-central-1` | Region to launch in. |
| `PROVISIONER_AWS_AMI_ID` | yes | `ami-0abc123def4567890` | Prebaked AMI (`infra/aws/bake-nodeodm-ami.sh`) or a stock Ubuntu 24.04 / Amazon Linux 2023 AMI. |
| `PROVISIONER_AWS_AMI_PREBAKED` | no (`false`) | `true` | Informational; the bootstrap detects Docker itself. |
| `PROVISIONER_AWS_INSTANCE_TYPES` | yes | `{"cpu": "c6i.2xlarge", "cpu-large": "c6i.8xlarge"}` | JSON object: class → EC2 instance type. Classes are what the app asks for. |
| `PROVISIONER_AWS_HOURLY_COSTS` | no | `{"cpu": 0.34, "cpu-large": 1.36}` | JSON: class → USD/h for the stored **estimate**. |
| `PROVISIONER_AWS_DEFAULT_CLASS` | no (first type) | `cpu` | Class used when the app asks for one that is not offered. |
| `PROVISIONER_AWS_SUBNET_ID` | yes | `subnet-0abc…` | Public subnet (internet route). |
| `PROVISIONER_AWS_SECURITY_GROUP_IDS` | yes | `sg-0abc…,sg-0def…` | Comma-separated. Must allow TCP `PROVISIONER_NODEODM_PORT` from the app host only. |
| `PROVISIONER_AWS_ASSOCIATE_PUBLIC_IP` | no (`true`) | `true` | Request a public address on the primary interface. |
| `PROVISIONER_AWS_ROOT_VOLUME_GB` | no (`200`) | `300` | gp3 root volume, deleted on termination. ODM needs ~10× the input size. |
| `PROVISIONER_AWS_KEY_NAME` | no | `webodm-debug` | SSH key pair for debugging nodes. |
| `PROVISIONER_AWS_IAM_INSTANCE_PROFILE` | no | `webodm-node` | Instance profile name or ARN for the node (not needed by the shipped bootstrap). |
| `PROVISIONER_AWS_TAG_PREFIX` | no (`webodm`) | `webodm` | Tag key prefix (`webodm:managed`, `webodm:deployment`, `webodm:task`, `webodm:org`, `webodm:class`). Changing it means changing the IAM policy. |
| `PROVISIONER_AWS_EXTRA_TAGS` | no | `{"CostCenter": "geo"}` | JSON of extra tags applied to instances and volumes. |
| `PROVISIONER_AWS_ENDPOINT_URL` | no | `http://localstack:4566` | Alternate EC2 endpoint (tests). |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN` (+ `_FILE`) | no (default chain) | — | **Provisioning** identity (`infra/aws/iam/provisioner-policy.json`). Compose mounts `secrets/aws_provisioner_*`. |

### Fixed provider (`PROVISIONER_PROVIDER=fixed`, development only)

| Variable | Default | Meaning |
|---|---|---|
| `PROVISIONER_FIXED_ENDPOINT` | *(required)* | `host:port` of an existing NodeODM (compose dev override: `nodeodm:3000`). The request's token is ignored. |

## Compose-level

| Item | Where | Meaning |
|---|---|---|
| `provisioner` service | `docker-compose.yml` | Built from `services/provisioner` until a published image is pinned. `backend` network only, read-only rootfs, no capabilities. |
| `geospatial_scratch` volume | `docker-compose.yml` | Mounted at `/scratch` in `geospatial` for S3 → S3 conversion. |
| `docker-compose.dev.yml` | repo root | MinIO + bucket init + `fixed` provider; dev only. `WEBODM_S3_BUCKET` defaults to `webodm-dev` there. |
| `scripts/init-secrets.sh` | repo root | Generates `provisioner_api_token.txt`, creates empty placeholders for the six cloud key files. |
